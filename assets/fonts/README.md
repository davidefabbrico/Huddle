# Fonts

## Chakra Petch (the app's text)

Regular, Medium, SemiBold and Bold, by The Chakra Petch Project Authors
(https://github.com/m4rc1e/Chakra-Petch), under the SIL Open Font License 1.1 (OFL-ChakraPetch.txt).
Unmodified, from @expo-google-fonts/chakra-petch. Squared letters with cut corners: a middle way between
a normal font and the pixel logo.

## Huddle Pixel (the "Huddle" logo)

Pixelify Sans Bold by The Pixelify Sans Project Authors (https://github.com/eifetx/Pixelify-Sans), under
the SIL Open Font License 1.1 (OFL-PixelifySans.txt).

Modified for Huddle: the "liga" and "dlig" ligatures are turned off (in this pixel font "fi" and "fl"
fuse into a glyph that reads like an "A"), and the family is renamed "Huddle Pixel" as the license
asks for modified versions. Made with fontTools from the files in @expo-google-fonts/pixelify-sans.
